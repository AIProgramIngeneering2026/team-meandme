# ADR-0004. Отмена Job до начала обработки

- Дата — 14 ноября 2026 года.
- Статус — принято.

## Контекст и ограничения

Пользователь может передумать, пока Job ждёт в очереди. После захвата задания Runner может уже получать файлы или выполнять анализ. Возможность прервать эти действия потребовала бы поддержки отмены в сетевом адаптере и в обоих Tool. Карта К6 требует определить ответ API в обоих случаях.

## Решение

Запрос `POST /jobs/{id}/cancel` переводит ожидающее задание из `created` в `cancelled` и возвращает HTTP 200. Время отмены записывается в `finished_at`. Поля `started_at` и `error` равны `null`. Отмена освобождает место в очереди, а запись и ключ создания сохраняются.

Runner и операция отмены обновляют запись в коротких транзакциях с условием `state = created`. Если первой фиксируется отмена, Runner пропускает задание и берёт следующее. Если первым фиксируется старт, отмена возвращает 409 `job_not_cancellable`. Для `done` и `failed` действует тот же отказ. Повтор отмены для `cancelled` возвращает сохранённый Job с тем же временем завершения.

Запрос результата отменённого задания возвращает 409 `job_cancelled`. Чтобы повторно запустить анализ, клиент создаёт новый Job с новым ключом. Права на отмену совпадают с доступом по ID в общем демонстрационном экземпляре. [HTTP API](../api/README.md#отмена-job) · [Границы демо](0003-demo-boundaries.md)

## Альтернативы

| Вариант | Почему отклонён |
|---|---|
| Выполнять все задания до конца | Даже ошибочно отправленная работа занимает очередь и ресурсы |
| Останавливать уже запущенный анализ | Нужны точки остановки в адаптере и обоих Tool, правила очистки ресурсов и разрешение гонки с завершением |

## Цена решения

Нужно согласовать две операции записи в БД и проверить случай, когда отмена приходит одновременно со стартом. Если Job быстро переходит в `running`, окно для отмены короткое.

## Условия пересмотра

Отдельно спроектируем остановку `running`, если появятся долгие или оплачиваемые операции. До добавления личных данных введём проверку владельца для чтения и отмены.
